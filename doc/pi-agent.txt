*pi-agent.nvim* A small Neovim assistant backed by Pi Agent

==============================================================================
COMMANDS                                                   *pi-agent-commands*

:PiAgentPanel~
  Open the Pi Agent panel on the right.

:PiAgent [prompt]~
  Inline-style interaction. With a visual range, selected text is included as
  context.

:PiAgentChat [prompt]~
  Open the chat buffer, or send a prompt to it.

:PiAgentChat Toggle~
  Toggle the chat buffer.

:PiAgentChat New~
:PiAgentChat Clear~
  Reset the current chat.

:'<,'>PiAgentChat Add~
  Add selected text to the chat input. Without a visual range, the current
  buffer is added.

:PiAgentCLI [prompt]~
  Open interactive Pi Agent in a floating terminal.

:PiAgentCmd [request]~
  Generate one Vim command and place it on the command line without executing
  it.

:PiAgentActions~
  Open the action palette.

:PiAgentBuffer [prompt]~
  Ask Pi Agent with the current buffer included as context.

:'<,'>PiAgentSelection [prompt]~
  Ask Pi Agent with the selected lines included as context.

:'<,'>PiAgentEdit [instruction]~
  Replace the selected lines with Pi Agent output.

:PiAgentLogin~
  Open Pi Agent login in a floating terminal.

:PiAgentStatus~
  Check whether Pi Agent authentication is ready.

==============================================================================
CHAT BUFFER                                             *pi-agent-chat-buffer*

Open the chat with:
>
  :PiAgentChat
<

Type below the `## You` heading and press Enter in normal or insert mode to
submit. `<C-s>` is also mapped as a fallback submit key. Press `q` in normal
mode to close the chat window.

==============================================================================
CONFIGURATION                                           *pi-agent-configuration*

Use:
>
  require("pi_agent").setup({
    agent_cmd = nil,
    sandbox = "read-only",
    approval = "never",
    model = nil,
    extra_args = {},
    terminal_args = {},
    system_prompt = "You are Pi Agent, a concise AI coding assistant running inside Neovim.",
    window = {
      width = 0.85,
      height = 0.85,
      border = "rounded",
    },
    chat = {
      width = 0.38,
      min_width = 52,
    },
    mappings = {
      submit = { "<CR>", "<C-s>" },
      close = "q",
    },
  })
<

With `agent_cmd = nil`, the plugin uses its bundled `bin/pi-agent` command.
That backend currently delegates to the local Codex CLI, so auth remains outside
Neovim and the plugin does not store API keys or tokens. Set `agent_cmd` to a
different executable when you have a separate Pi Agent runtime.
